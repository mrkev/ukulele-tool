About this chord chart

Every chord is drawn for a ukulele in standard GCEA (C6) tuning, with the strings left to right: G, C, E, A. A dot marks where to press, and an O above a string means it is played open. Chords are grouped by root note — C, Db, D, Eb, E, F, Gb, G, Ab, A, Bb and B — and each root has major, minor, dominant 7th, minor 7th, diminished, augmented, 6th, major 7th and 9th voicings.

Playback uses a sampled ukulele soundfont, so what you hear is a real strum. Starred chords are saved in your browser and will be here the next time you visit. The chart is free and open source on GitHub.
